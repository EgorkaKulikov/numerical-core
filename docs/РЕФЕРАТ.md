# Реферат программы для ЭВМ

Материалы к заявке на государственную регистрацию программы для ЭВМ.

## Название программы

numerical-core — библиотека численных примитивов для плотных вычислений на платформе JVM.

## Правообладатель и автор

Куликов Егор Константинович, физическое лицо. Правообладатель и автор совпадают.

## Реферат

Программа представляет собой библиотеку для платформы JVM, реализующую численные примитивы плотной линейной
алгебры и квадратуры с контролем достоверности результатов. Область применения — научные и инженерные расчёты
с плотными системами линейных уравнений от сотен до десятков тысяч неизвестных на рабочих станциях и кластерах.

Проблема. Существующие средства для JVM либо дают прямой доступ к BLAS/LAPACK без оценки достоверности
результата (netlib, JavaCPP Presets для OpenBLAS и MKL; `info = 0` означает лишь завершение разложения, а не
корректность решения), либо реализованы на Java (EJML, ojAlgo, Hipparchus, Apache Commons Math) и уступают
нативным библиотекам в производительности, не используя ресурсы целевой системы (Intel MKL, AMD AOCL,
Apple Accelerate); ни одно не сообщает вызывающей программе, сколько значащих цифр решения достоверны.

Функциональные возможности: решение систем линейных уравнений LU-разложением с проверкой обратной ошибки и
типизированной оценкой прямой ошибки; число обусловленности обращением либо оценкой LAPACK; спектр симметричных
матриц; разложение Холецкого; матричные операции и нормы; составная квадратура Гаусса–Лежандра; параллельная
сборка матриц; классификация измеренных величин относительно шума округления и наблюдаемый порядок сходимости.

Отличительные особенности. Достоверность закреплена в системе типов: недостоверная величина не может быть
использована как число без явного решения вызывающей программы, тогда как существующие библиотеки возвращают
решение и число обусловленности без признака достоверности. Матрицы хранятся в столбцовом порядке BLAS/LAPACK
и передаются без переупорядочения, с копией только там, где LAPACK перезаписывает вход, так что исходные
матрицы не изменяются, а скорость определяется библиотекой целевой системы. Единая семантика проверок, ошибок и
форматов результата для всех реализаций BLAS/LAPACK — Intel MKL, AMD AOCL, OpenBLAS, Apple Accelerate и
переносимой реализации на Java — с автоматическим выбором реализации при запуске и явной диагностикой выбранного
варианта. Квадратура, параллельная сборка матриц и анализ сходимости, отсутствующие в BLAS/LAPACK, выполнены в
едином стиле с теми же гарантиями.

## Тип ЭВМ

IBM PC-совместимые, Apple Silicon и иные, поддерживаемые виртуальной машиной Java версии 21.

## Язык программирования

Kotlin 2.0.

## Операционная система

Linux, macOS, Windows с установленной виртуальной машиной Java версии 21 или новее.

## Объём программы

Около 115 КБ исходного кода (2082 строки в 14 файлах на языке Kotlin, модули `core/src/main`
и `openblas/src/main`). Размер скомпилированных артефактов: `numerical-core-1.0.0.jar` —
72 КБ, `numerical-core-openblas-1.0.0.jar` — 6 КБ.

## Год создания

2026.

## Зависимости

- виртуальная машина Java версии 21 или новее;
- netlib 3.2.0 (`dev.ludovic.netlib`, лицензия MIT) — слой доступа к BLAS/LAPACK с
  переносимой реализацией на Java;
- при использовании модуля `numerical-core-openblas` — OpenBLAS через JavaCPP Presets
  (`org.bytedeco:openblas`).

Сборка: Gradle 8.9, Kotlin 2.0.0.
