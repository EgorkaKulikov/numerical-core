# Реферат программы для ЭВМ

Материалы к заявке на государственную регистрацию программы для ЭВМ.

## Название программы

numerical-core — библиотека численных примитивов для плотных вычислений на платформе JVM.

## Правообладатель и автор

Куликов Егор Константинович, физическое лицо. Правообладатель и автор совпадают.

## Реферат

Программа представляет собой библиотеку для платформы JVM, реализующую набор численных
примитивов плотной линейной алгебры и квадратуры с контролем достоверности результатов.
Область применения — научные и инженерные расчёты, требующие решения плотных систем
линейных алгебраических уравнений размера от сотен до десятков тысяч неизвестных с оценкой
точности полученного решения, на рабочих станциях и высокопроизводительных вычислительных
системах.

Функциональные возможности: решение систем линейных уравнений методом LU-разложения с
проверкой обратной ошибки и типизированной оценкой прямой ошибки; вычисление числа
обусловленности матрицы через явное обращение либо оценкой по LU-разложению; вычисление
спектра симметричных матриц и спектрального числа обусловленности; разложение Холецкого с
проверкой положительной определённости; матрично-векторные и матрично-матричные операции,
взвешенная форма AᵀWA, матричные нормы; составная квадратура Гаусса–Лежандра по
произвольному разбиению отрезка; параллельная сборка матриц с управляемой степенью
параллелизма; классификация измеренных величин относительно уровня шума округления и
вычисление наблюдаемого порядка сходимости по достоверным измерениям.

Отличительные особенности: результат каждой операции сопровождается типизированной оценкой
достоверности, так что недостоверная величина не может быть использована как число без
явного решения вызывающей программы; единая семантика проверок и ошибок для всех реализаций
BLAS/LAPACK — системной библиотеки (Intel MKL, AMD AOCL, OpenBLAS, Apple Accelerate),
упакованной OpenBLAS и переносимой реализации на Java; хранение матриц в столбцовом порядке
BLAS/LAPACK и передача их без переупорядочения, с копией только там, где LAPACK
перезаписывает вход, так что исходные матрицы не изменяются; автоматический выбор
реализации при запуске с явной диагностикой выбранного варианта.

## Тип ЭВМ

IBM PC-совместимые, Apple Silicon и иные, поддерживаемые виртуальной машиной Java версии 21.

## Язык программирования

Kotlin 2.0.

## Операционная система

Linux, macOS, Windows с установленной виртуальной машиной Java версии 21 или новее.

## Объём программы

Около 115 КБ исходного кода (2082 строки в 14 файлах на языке Kotlin, модули `core/src/main`
и `openblas/src/main`). Размер скомпилированных артефактов: `numerical-core-1.0.0.jar` —
72 КБ, `numerical-core-openblas-1.0.0.jar` — 6 КБ.

## Год создания

2026.

## Зависимости

- виртуальная машина Java версии 21 или новее;
- netlib 3.2.0 (`dev.ludovic.netlib`, лицензия MIT) — слой доступа к BLAS/LAPACK с
  переносимой реализацией на Java;
- при использовании модуля `numerical-core-openblas` — OpenBLAS через JavaCPP Presets
  (`org.bytedeco:openblas`).

Сборка: Gradle 8.9, Kotlin 2.0.0.
