# Реферат программы для ЭВМ

Материалы к заявке на государственную регистрацию программы для ЭВМ.

## Название программы

numerical-core — библиотека численных примитивов для плотных вычислений на платформе JVM.

## Правообладатель и автор

Куликов Егор Константинович, физическое лицо. Правообладатель и автор совпадают.

## Реферат

Программа представляет собой библиотеку для платформы JVM, реализующую численные примитивы плотной линейной
алгебры и квадратуры с контролем достоверности результатов. Область применения — научные и инженерные расчёты
с плотными системами линейных алгебраических уравнений (СЛАУ) от сотен до десятков тысяч неизвестных на рабочих
станциях и вычислительных кластерах.

Существующие средства для платформы JVM решают задачу частично. Интерфейсы вызова BLAS/LAPACK (netlib, JavaCPP
Presets для OpenBLAS и MKL) предоставляют процедуры в исходной форме без оценки достоверности результата: код
возврата `info = 0` свидетельствует лишь о завершении разложения, но не о корректности решения. Библиотеки на
языке Java (EJML, ojAlgo, Hipparchus, Apache Commons Math) не используют системные реализации BLAS/LAPACK
(Intel MKL, AMD AOCL, Apple Accelerate) и уступают им в производительности. Ни одно из указанных средств не
сообщает вызывающей программе, сколько значащих цифр решения достоверны.

Программа обеспечивает следующие функциональные возможности: решение СЛАУ LU-разложением с проверкой обратной
ошибки и типизированной оценкой прямой ошибки; вычисление числа обусловленности обращением матрицы либо оценкой
средствами LAPACK; вычисление спектра симметричных матриц; разложение Холецкого; матричные операции и нормы;
составную квадратуру Гаусса–Лежандра; параллельную сборку матриц; классификацию измеренных величин относительно
шума округления и вычисление наблюдаемого порядка сходимости.

Отличительные особенности программы состоят в следующем. Достоверность результата закреплена в системе типов:
недостоверная величина не может быть использована как число без явного решения вызывающей программы, тогда как
существующие библиотеки возвращают решение и число обусловленности без признака достоверности. Матрицы хранятся
в столбцовом порядке BLAS/LAPACK и передаются без переупорядочения; копия создаётся только там, где LAPACK
перезаписывает входные данные, поэтому исходные матрицы не изменяются, а производительность определяется
системной реализацией. Семантика проверок, исключений и форматов результата едина для всех реализаций
BLAS/LAPACK (Intel MKL, AMD AOCL, OpenBLAS, Apple Accelerate, переносимая реализация на Java); реализация
выбирается автоматически при запуске, выбранный вариант сообщается явно. Квадратура, параллельная сборка матриц
и анализ сходимости, отсутствующие в BLAS/LAPACK, выполнены в едином стиле с теми же гарантиями.

## Тип ЭВМ

IBM PC-совместимые, Apple Silicon и иные, поддерживаемые виртуальной машиной Java версии 21.

## Язык программирования

Kotlin 2.0.

## Операционная система

Linux, macOS, Windows с установленной виртуальной машиной Java версии 21 или новее.

## Объём программы

Около 115 КБ исходного кода (2082 строки в 14 файлах на языке Kotlin, модули `core/src/main`
и `openblas/src/main`). Размер скомпилированных артефактов: `numerical-core-1.0.0.jar` —
72 КБ, `numerical-core-openblas-1.0.0.jar` — 6 КБ.

## Год создания

2026.

## Зависимости

- виртуальная машина Java версии 21 или новее;
- netlib 3.2.0 (`dev.ludovic.netlib`, лицензия MIT) — слой доступа к BLAS/LAPACK с
  переносимой реализацией на Java;
- при использовании модуля `numerical-core-openblas` — OpenBLAS через JavaCPP Presets
  (`org.bytedeco:openblas`).

Сборка выполняется средствами Gradle 8.9 и Kotlin 2.0.0.
